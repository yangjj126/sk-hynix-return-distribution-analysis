# SK Hynix Daily Return Distribution Analysis

## Overview

This project analyzes approximately 1,000 daily returns of SK Hynix
to examine whether stock returns follow a normal distribution.

The purpose of this project is to apply basic statistical concepts
to real financial market data using Python.

## Analysis

The project includes:

- Collection of SK Hynix historical stock price data
- Calculation of daily returns
- Mean and standard deviation analysis
- Histogram of daily returns
- Comparison with a theoretical normal distribution
- Q-Q Plot
- Shapiro-Wilk normality test

## Tools

- Python
- pandas
- NumPy
- matplotlib
- SciPy
- yfinance

## Research Question

Do the daily returns of SK Hynix follow a normal distribution?

## Methods

Approximately 1,000 daily stock returns were collected and analyzed.

The empirical return distribution was compared with a theoretical
normal distribution using:

1. Histogram and probability density
2. Q-Q Plot
3. Shapiro-Wilk normality test

## Motivation

This project was conducted as part of my study of quantitative finance,
financial risk management, probability, and statistical analysis.

It also serves as a foundation for further study of Monte Carlo simulation,
Value at Risk (VaR), and financial risk modeling.
